# Bem Aqui Home Finder

# PROMPT PARA LOVABLE — BEM AQUI IMÓVEIS

Crie uma plataforma imobiliária profissional, moderna, completa e responsiva chamada **BEM AQUI IMÓVEIS**, seguindo a identidade visual da imagem de referência anexada.

O projeto deve ser desenvolvido como um sistema real, com frontend funcional, backend, banco de dados, autenticação e estrutura preparada para expansão.

Não crie apenas uma demonstração visual ou landing page. Desenvolva uma aplicação com páginas, funcionalidades, navegação e fluxos reais.

# 1. IDENTIDADE VISUAL

Crie uma identidade visual premium, transmitindo confiança, sofisticação e tecnologia.

**Paleta de cores:**
- Azul-marinho profundo: #071D3A.
- Azul institucional: #0B315B.
- Dourado: #E8AD32.
- Branco: #FFFFFF.
- Cinza claro: #F4F6FA.
- Texto escuro: #17243A.

**Estilo:**
- Design moderno e sofisticado.
- Cards com bordas suaves.
- Sombras discretas.
- Ícones profissionais.
- Animações leves.
- Excelente experiência em desktop, tablet e celular.
- Layout limpo, sem excesso de informações.

Utilize a imagem de referência como inspiração para o visual, principalmente o azul-marinho, dourado e apresentação premium dos imóveis.

# 2. ESTRUTURA DA PLATAFORMA

A plataforma terá três interfaces independentes e integradas:

1. Portal público para visitantes e compradores.
2. Painel profissional para corretores e imobiliárias.
3. Painel administrativo para os responsáveis pela plataforma.

# 3. PORTAL PÚBLICO

Criar uma página inicial contendo:

- Header com logotipo BEM AQUI IMÓVEIS.
- Menu: Início, Comprar, Alugar, Anunciar, Investir e Contato.
- Banner principal com imagem de imóvel de alto padrão.
- Texto: "Seu próximo endereço começa aqui."
- Barra de pesquisa de imóveis.
- Filtros por cidade, bairro, preço, tipo de imóvel e finalidade.
- Imóveis em destaque.
- Imóveis recentes.
- Imóveis para venda.
- Imóveis para locação.
- Seção de oportunidades de investimento.
- Corretores em destaque.
- Parceiros imobiliários.
- Depoimentos.
- Botão de atendimento pelo WhatsApp.
- Rodapé institucional completo.

Cada imóvel deve possuir uma página individual com:

- Galeria de fotos.
- Vídeos, quando disponíveis.
- Descrição completa.
- Valor de venda ou aluguel.
- Localização.
- Metragem.
- Quantidade de quartos.
- Banheiros.
- Vagas de garagem.
- Características e comodidades.
- Mapa de localização.
- Informações do corretor responsável.
- Botão de WhatsApp.
- Formulário de interesse.
- Opção de favoritar.

# 4. PAINEL PROFISSIONAL — CORRETOR E IMOBILIÁRIA

Criar um painel com login e controle de acesso.

Dashboard com:
- Total de imóveis cadastrados.
- Imóveis publicados.
- Imóveis aguardando aprovação.
- Propostas recebidas.
- Negociações em andamento.
- Leads recebidos.
- Relatórios de desempenho.

**Gerenciamento de imóveis:**
- Cadastrar imóveis.
- Editar imóveis.
- Excluir imóveis.
- Enviar várias fotografias.
- Inserir vídeos.
- Informar endereço e localização.
- Definir preço.
- Selecionar venda ou aluguel.
- Adicionar descrição e características.
- Salvar como rascunho.
- Enviar para aprovação.
- Acompanhar status de publicação.

**Gerenciamento comercial:**
- Receber interessados.
- Visualizar propostas.
- Aprovar ou recusar propostas.
- Registrar negociações.
- Acompanhar histórico de contatos.
- Gerenciar clientes e leads.

**Relatórios:**
- Visualizações de imóveis.
- Quantidade de contatos.
- Propostas recebidas.
- Conversões.
- Exportação de relatórios em PDF.

# 5. SIMULADOR FINANCEIRO

Criar um simulador financeiro funcional.

Permitir informar:
- Valor do imóvel.
- Valor da entrada.
- Quantidade de parcelas.
- Taxa de juros.
- Sistema de amortização.

Apresentar:
- Valor financiado.
- Valor estimado das parcelas.
- Total de juros.
- Total pago.
- Tabela de amortização.
- Comparação de cenários.

Implementar sistemas SAC e PRICE.

Deixar claro que os resultados são simulações e não representam uma aprovação de financiamento bancário.

# 6. PROJEÇÃO DE VALORIZAÇÃO

Criar ferramenta para estimar valorização imobiliária.

Permitir configurar:
- Valor atual do imóvel.
- Taxa anual estimada.
- Período de projeção.
- Cenário conservador.
- Cenário base.
- Cenário otimista.

Exibir gráficos comparativos e evolução estimada do patrimônio.

Não apresentar projeções como garantias de retorno financeiro.

# 7. ANÁLISE DE INVESTIMENTO

Criar módulo para avaliação de oportunidades imobiliárias.

Apresentar:
- Valor de aquisição.
- Custos adicionais.
- Valor estimado de aluguel.
- Rendimento mensal estimado.
- Rendimento anual estimado.
- Rentabilidade percentual.
- Comparação entre imóveis.
- Estimativa de retorno do investimento.

# 8. SISTEMA DE PROPOSTAS E PARCERIAS

Criar um sistema comercial com:

- Envio de propostas de compra.
- Envio de propostas de aluguel.
- Contrapropostas.
- Histórico de negociações.
- Registro de acordos.
- Identificação dos participantes.
- Status de cada negociação.
- Notificações sobre atualizações.

# 9. PAINEL ADMINISTRATIVO

Criar uma interface exclusiva para administradores.

Dashboard geral com:
- Total de usuários.
- Total de corretores.
- Total de imobiliárias.
- Total de imóveis.
- Imóveis publicados.
- Imóveis aguardando aprovação.
- Propostas realizadas.
- Leads recebidos.

Funcionalidades:
- Gerenciar usuários.
- Gerenciar corretores.
- Gerenciar imobiliárias.
- Aprovar ou rejeitar cadastros.
- Aprovar ou rejeitar anúncios.
- Editar e remover imóveis.
- Gerenciar categorias.
- Gerenciar banners.
- Gerenciar parceiros.
- Visualizar denúncias.
- Gerenciar permissões.
- Consultar logs de atividades.

# 10. MARKETING E INTEGRAÇÕES

Preparar estrutura para:

- Compartilhamento de imóveis nas redes sociais.
- Links personalizados.
- SEO para páginas de imóveis.
- Integração com WhatsApp.
- Google Maps.
- Google Analytics.
- Notificações por e-mail.
- Notificações internas.
- Cards de compartilhamento.

Deixar as integrações preparadas para receber credenciais reais, sem inventar chaves de API.

# 11. SEGURANÇA E LGPD

Implementar:

- Autenticação segura.
- Recuperação de senha.
- Controle de acesso por perfil.
- Proteção de rotas.
- Validação dos dados.
- Políticas de acesso ao banco.
- Proteção de informações pessoais.
- Consentimento para tratamento de dados.
- Registro de atividades administrativas.
- Exclusão e atualização de dados pessoais conforme a LGPD.

Um corretor não pode acessar informações privadas de outro corretor sem autorização.

# 12. BANCO DE DADOS E BACKEND

Utilizar Supabase como backend, caso disponível no projeto Lovable.

Criar estrutura para as seguintes entidades:

- profiles
- users
- agencies
- brokers
- properties
- property_images
- property_videos
- property_features
- favorites
- leads
- proposals
- negotiations
- partnerships
- notifications
- financial_simulations
- investment_analyses
- property_valuations
- activity_logs

Criar relacionamentos adequados entre as tabelas.

Utilizar Supabase Storage para imagens e arquivos.

Implementar Row Level Security (RLS) para proteger os dados.

Não deixar informações sensíveis expostas no frontend.

# 13. RESPONSIVIDADE E EXPERIÊNCIA

O sistema deve funcionar perfeitamente em:

- Computadores.
- Notebooks.
- Tablets.
- Smartphones.

Criar menus responsivos, tabelas adaptáveis, formulários organizados e dashboards com gráficos.

Evitar botões sem funcionalidade, links quebrados e telas sem conteúdo.

# 14. TECNOLOGIAS

Preferência por:

- React.
- TypeScript.
- Tailwind CSS.
- Componentes reutilizáveis.
- Supabase.
- Banco PostgreSQL.
- Biblioteca de gráficos.
- Integrações via APIs.

Organizar o código em componentes, páginas, serviços, hooks e módulos.

# 16. REGRAS IMPORTANTES

1. Não desenvolver tudo em uma única página.
2. Não utilizar somente dados estáticos para simular funcionalidades.
3. Implementar autenticação e persistência real dos dados.
4. Criar páginas completas para cada módulo.
5. Garantir que cada perfil tenha suas permissões específicas.
6. Criar dados demonstrativos apenas para facilitar os testes, identificando-os como dados fictícios.
7. Não simular integrações como se já estivessem funcionando.
8. Priorizar uma arquitetura escalável e de fácil manutenção.
9. Não remover funcionalidades já implementadas ao desenvolver novos módulos.
10. Antes de finalizar, testar os principais fluxos da aplicação.

Entregar uma plataforma imobiliária completa, profissional, escalável e pronta para evoluir comercialmente, com uma experiência visual premium inspirada na referência enviada.

A marca deve transmitir confiança, tecnologia, segurança e oportunidades imobiliárias.
